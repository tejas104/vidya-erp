# School document formats

Only an administrator with access to this school can change its document
formats. Choose a school and document type, then edit the school name, accent
colour and footer. The preview shows the presentation fields; it does not
invent pupil data. Select **Save format** to create a new audited version.

You may attach a PDF or DOCX sample up to 1 MB. Vidya stores it privately as a
reference for a person mapping the school's design. Uploading a sample does
not automatically change the generated PDF. The controlled editor currently
sets branding and footer; finer page layout is planned.

New report cards use the saved style when issued. Attendance review PDFs use
the style present when requested, even if the worker finishes later. Existing
documents keep their earlier appearance. Certificate style can be configured,
but certificate issuance is not yet available. Excel and CSV attendance exports
stay in their structured data formats.
