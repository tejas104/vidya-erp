# Teachers and class roles

Use the teacher directory to keep staff records, sign-ins, and class assignments together. Only an administrator can make these changes.

## Add or find a teacher

Enter a unique staff number and the teacher's full name, then select **Add teacher**. The teacher remains in the directory after reloading the page. Search by name or staff number; use **Next** and **Previous** when the list is long.

## Give access

Use **Issue sign-in** to create a staff account for a teacher without one. The temporary password is displayed once. Hand it to that teacher privately and close the dialog after recording it safely. An existing staff sign-in can be linked instead; a family, student, administrator, or account from another school cannot be linked as a teacher.

Use **Assign** to choose a class role. A subject teacher teaches a selected subject; a class teacher owns whole-class work for that class. The server derives teaching access from these assignments. Removing an assignment revokes the matching derived access.

## Keep records current

Use **Edit** to update the name or set a teacher inactive. Inactive teachers lose the access derived from assignments. Do not issue a new sign-in for an inactive record. If an existing password needs replacement, use the account reset process rather than creating a second account.
