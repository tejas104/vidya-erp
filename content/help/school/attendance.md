# Record school attendance

Record attendance for a section you are authorized to teach. The screen starts every learner as present so the common classroom flow is quick to review.

## Who can use this

Subject teachers record their own teaching period. Class teachers can record attendance for their assigned sections. The server checks the selected section and teaching scope, so staff cannot use this screen to record another class's attendance.

## Before you start

You need an assigned class or teaching period and an enrolled section roster. If you opened the screen from **Now**, its section, subject, period, and date may already be selected for you.

## Record a section

1. Open **Attendance** from the sidebar, or select **Mark attendance** from **Now** for the current period.
2. Choose the **Section** and **Date**. Review the class and section shown in the selector.
3. Review the roster. Everyone starts as present; select a learner to toggle between present and absent.
4. Use the secondary selector below a learner for **Late** or **Excused** when needed. Select **All present** to restore the whole roster to present for review.
5. Confirm the present, absent, late, and excused totals, then select **Save attendance**.

The attendance record is saved for the selected date and period. The confirmation explains that analytics must be recomputed before the new attendance appears on the dashboard.

If attendance was already saved for that section, date, period, and subject, the screen shows its recorded counts instead of a new entry form. Ask a class teacher or administrator to use the audited correction flow when a recorded status must change. If the screen cannot check for an existing register, retry the check before saving.

If there are no sections, open the relevant period from your **Today** card or ask the office to verify your teaching assignment. If the roster cannot load, select the retry action and check the selected section. If saving shows an error, correct the indicated problem and select **Save attendance** again; do not assume an unsaved roster has been recorded.
