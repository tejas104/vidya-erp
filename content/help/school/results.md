# School results

The Results page shows the path from term setup to marks and report cards. It leaves college credits and SGPA out of the school workflow.

1. Open **Academic terms** to set dates and assessment weights.
2. Open **Marks** to record scores for each class and subject.
3. Open **Report cards** to preview, generate, and publish the finished record to families.

An administrator can create a grade scale under **Grading rules**. Teachers select that scale when they create the first assessment for a term. The term stores its grading basis so later work stays reproducible. School grade scales are retained; when grading rules change, create a new scale for future terms. Principals can review the scales but cannot create them.
