# Teacher attendance

Use this register to record teachers' daily presence. It is separate from class attendance for pupils.

## Who can use this

Administrators can record and correct teacher presence. Principals can review the register but cannot change it. The school access check runs on the server for every request.

## Record a day

1. Choose the school, date, and teacher search if needed.
2. Select **Present**, **Absent**, **Late**, or **On leave** for each teacher you need to record. An optional note can explain a late arrival or correction.
3. Use **Mark unmarked present** to fill the still-empty rows on the current page. Existing statuses and notes remain as they are.
4. Review the counts and select **Save changes**. Only rows changed on this page are submitted. Wait for the saved confirmation before leaving.

The date can be changed to review or correct an earlier record. Inactive teachers remain visible for historical review but cannot be edited. **On leave** is a manual presence status; it does not approve a leave request.

If saving fails, the entries remain on the page so you can review them and retry. Search and pagination show up to 50 teachers at a time; save changes before switching pages.
