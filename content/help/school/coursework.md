# Assignments and study material

Use Coursework to manage assignments and study material for a class and subject you teach.

## Who can use this

The coursework screen is for teachers with an assigned teaching subject. The selected **Class · subject** determines what can be created, evaluated, or shared; staff cannot use it to manage another teacher's subject.

## Before you start

You need an assigned class and subject. Choose the correct **Class · subject** before creating anything. For study material, have the file and a clear title ready; the current form accepts a file up to 1 MB.

## Create and manage assignments

1. Open **Coursework** from the sidebar.
2. Choose the required **Class · subject**.
3. Select **New assignment**.
4. Enter a **Title**, **Instructions**, **Due on** date, and optional **Max score**, then select **Create**.
5. Use **Evaluate** on an assignment to review submissions and save an available score. Use **Delete** only when the assignment has no submissions; the screen blocks deletion once submissions exist.

The assignment appears in the **Assignments** table with its due date, maximum score, and submission count. A missing title prevents creation. If you see **No subject you teach**, ask the administrator to verify your teaching assignment rather than selecting another staff member's class.

## Share study material

1. Select **Upload material** for the chosen class and subject.
2. Enter a **Title**, choose the **File (≤1MB)**, and select **Upload**.
3. Review the item in **Study material**; its row provides **Download** for staff review.

If upload fails, verify the title and file size, then retry. If a list cannot load, use its retry action before creating a duplicate assignment or uploading the file again.
