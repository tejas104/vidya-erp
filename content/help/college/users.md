# Managing sign-ins and access

Every login is a user account with one or more roles and scope grants.
Changing either signs that user out everywhere, immediately.

## Steps

1. Open **Users** from the sidebar.
2. Click **New user**, set a username and display name, and save to create the account.
3. Open a user's row to add or change their **roles**.
4. Add a **scope grant** to limit what a role can see or act on (e.g. one department only).
5. Click **Verify grants** to check that a user's current grants still resolve correctly.
6. If someone is locked out, issue a password reset token or set a new password from their row.
