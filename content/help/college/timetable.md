# Building the weekly timetable

Set the college's period template once, then place each subject into its
weekly slot per section.

## Steps

1. Open **Timetable** from the sidebar.
2. If no periods exist yet, click **Edit periods** and define the day (e.g. P1 09:00–09:50, P2 09:50–10:40…).
3. Pick a **section**, then click an empty slot on the grid to schedule a subject and teacher into it.
4. Add a room if you want one shown on the grid.
5. Click a filled slot to unschedule it.

The system refuses a double-booking — a teacher, section, or room already busy in that period answers with a clear message instead of overwriting anything.
