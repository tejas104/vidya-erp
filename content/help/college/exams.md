# Setting up exams

Build the exam timetable in two steps: create a series, then schedule each
paper inside it.

## Steps

1. Open **Exams** from the sidebar.
2. Click **New series** and give it a name (e.g. Midterm) and a term.
3. Select the series, then add a paper: date, start time, end time, and room.
4. Repeat for each paper the series needs.

A paper that clashes with a regular lesson in the same room shows a warning, but it never blocks you from saving — check the warning before you confirm.
